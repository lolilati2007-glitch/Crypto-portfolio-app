# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-08-18

### Added
- Initial release of Crypto Portfolio Tracker
- Add/remove cryptocurrency assets
- Real-time price updates from CoinGecko API
- Portfolio dashboard with key metrics
- Asset table with detailed holdings
- Portfolio distribution pie chart
- Performance comparison bar chart
- Local storage persistence
- Dark theme UI
- Support for 10 major cryptocurrencies
- Responsive design
- TypeScript support

### Features
- ✅ Add cryptocurrencies to portfolio
- ✅ View portfolio value and gains/losses
- ✅ Real-time price updates (60-second intervals)
- ✅ Visual charts and analytics
- ✅ Persistent local storage
- ✅ Clean, modern UI
